## 🛠️ Stack Tecnológico

- **Framework:** React 18 + TypeScript + Vite 6
- **Estilos:** Tailwind CSS con tokens editoriales
- **Iconografía:** Lucide Icons + SVGs nativos
- **Celebraciones:** Canvas Confetti
- **Persistencia:** Store reactivo desacoplado con LocalStorage y capa exportable
